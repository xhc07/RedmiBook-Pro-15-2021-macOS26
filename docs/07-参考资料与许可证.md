## 3. 许可证

### 3.1 本仓库原创内容

`SSDT-ADPX`、`SSDT-BRTN` 源码、`Patches/ours/`、`Tools/`、`docs/`、`README.md`：
**MIT License**（见仓库根目录 `LICENSE`）。

### 3.2 第三方组件

各组件**保留其原始许可证**，以各上游仓库的 `LICENSE` 为准：

| 类型 | 说明 |
|---|---|
| OpenCore | BSD-3-Clause（acidanthera） |
| Lilu / VirtualSMC / AppleALC / BrightnessKeys / NVMeFix / RestrictEvents / VoodooPS2 | 多数为 MIT（以仓库为准） |
| VoodooI2C | GPL 系（以仓库为准） |
| AirportItlwm / IntelBluetoothFirmware | GPL-2.0（以仓库为准） |
| SimpleHDA | 以 laobamac 仓库为准 |
| 4 个 eDP 补丁（`Patches/third-party/`） | 来自同机型仓库，版权归其作者，按其仓库许可使用 |

**重要**：`Drivers/WhateverXe-Graphics-0.4.1.pkg` 中包含 **Apple 原厂 kext**
（`AppleIntelTGLGraphics`、`AppleIntelTGLGraphicsFramebuffer`），版权归 Apple，
**不得再分发或商用**。本仓库仅为方便同机型用户复现而附上该安装包，请自行判断合规性；
更稳妥的做法是自行从 macOS 安装包中提取。

### 3.3 SMBIOS / 序列号

本仓库的 `EFI/OC/config.plist` **已清空序列号**。请自行用 GenSMBIOS / OCAT 生成，
不要使用他人序列号（会导致 Apple 服务异常，也可能影响他人）。
