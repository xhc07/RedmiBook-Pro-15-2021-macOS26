# 安装指南

> 目标：在 RedmiBook Pro 15 2021 上跑起 macOS 26，核显加速可用。
> 全程假设你**不动内置硬盘上的 Windows**（本配置在外置 USB SSD 上验证）。

## 0. 前置条件

| 项目 | 要求 |
|---|---|
| 一台能用的 Mac / 黑苹果 | 用来制作安装盘、编辑 EFI |
| 16 GB 以上 U 盘 | 存放恢复镜像或安装器 |
| 目标磁盘 | NVMe 或外置 USB SSD（外置也可，但睡眠相关问题会更复杂） |
| OpenCore | 1.0.x（本仓库 EFI 基于 1.0.8 结构） |
| macOS 安装包 | 请自行从 App Store 获取，本仓库不包含 |

## 1. BIOS 设置

RedmiBook 的 Insyde BIOS 把大部分选项藏起来了，必要的只有一项：

### 1.1 DVMT 改成 128 MB（必须）

WhateverXe 需要至少 128 MB 的预分配显存，否则加速引擎起不来。

```bash
# 在 macOS 里（需要 root）读取当前值
sudo ./Tools/set-dvmt.sh show
# 写入 128 MB
sudo ./Tools/set-dvmt.sh 128
# 重启后确认（i915/WhateverXe 日志会显示 128 MiB）
```

原理：UEFI 变量 `SaSetup`（GUID `72C5E28C-7783-43A1-8767-FAD73FCCAFA4`）偏移 `0x84`：
`0xFE`=60M（出厂）、`0x02`=64M、`0x03`=96M、`0x04`=128M、`0x05`=160M。

> 恢复办法：BIOS 里 "Load defaults"（F9），或恢复脚本自动保存的 `/tmp/sas.bak`。

### 1.2 其他（如 BIOS 里有就改）

- Secure Boot：**关闭**
- Fast Boot：关闭
- VT-d：可关（本配置用 `DisableIoMapper`）

## 2. 部署 EFI

1. 挂载目标磁盘的 ESP（200 MB 的 EFI 分区）
2. 把本仓库 `EFI/` 整个复制到 ESP 根目录
3. **生成你自己的 SMBIOS**（`MacBookPro16,2`），填入 `EFI/OC/config.plist` 的
   `PlatformInfo → Generic`：

```
SystemProductName  MacBookPro16,2
SystemSerialNumber <用 GenSMBIOS / OCAT 生成>
MLB                <同上>
SystemUUID         <同上>
ROM                <你的网卡 MAC，6 字节>
```

> 仓库里的序列号已清空。**不要**直接使用别人的序列号。

4. 检查 `Misc → Boot → Hibernatemode` 为 `None`（本仓库已设置）。

## 3. 安装 macOS

按常规 OpenCore 流程安装即可（本仓库不重复教程）。安装完成后先不要急着装核显驱动，
确认能进系统、USB 可用。

## 4. 安装核显驱动（关键步骤）

WhateverXe 由两部分组成：

| 部分 | 位置 | 说明 |
|---|---|---|
| `WhateverXe.kext` | EFI | 主驱动（本仓库已含 0.8.2） |
| `AppleIntelTGLGraphics` / `Framebuffer` | `/Library/Extensions` + AuxKC | Apple 原厂 kext（由 Graphics 安装包放入） |
| `AppleIntelTGLCompat` | `/Library/Extensions` + AuxKC | 兼容层，**版本必须与 WhateverXe 配对** |

### 4.1 安装 Graphics（会装 Compat 0.8.0）

```bash
sudo ./Tools/reinstall-graphics.sh
```

### 4.2 配对 Compat 版本

| EFI 里的 WhateverXe | 需要的 Compat |
|---|---|
| 0.8.2（本仓库） | **0.8.1** |
| 0.8.0 | 0.8.0 |

```bash
sudo ./Tools/install-compat.sh 0.8.1
```

该脚本会重建 AuxKC 并校验版本，失败时不会替换。

### 4.3 重启

```bash
sudo reboot
```

## 5. 验证

```bash
./Tools/verify.sh
```

期望输出：

```
WhateverXe (0.8.2)     AppleIntelTGLCompat (0.8.1)     AppleIntelTGLGraphics (16.0.0)
TGLEDPKept = 5         TGLEDPKeepReady = Yes          TGLEDPExtCapMasked = 4
Resolution: 3200 x 2000   Metal 2
电池: 有 ExternalConnected / 充电状态
触摸板 HID 设备: > 0
```

## 6. 安装后必做的设置

```bash
# 禁止睡眠（本机 S3 唤醒会 panic，详见 docs/05）
sudo pmset -a disablesleep 1 sleep 0 hibernatemode 0 standby 0 powernap 0 tcpkeepalive 0
```

## 7. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 开机黑屏、`FB0 is not enabled` | 缺少补丁 04 / 没加 `-wex-edp-no-extcap` | 检查 boot-args |
| 加速没起来（菜单栏卡顿） | Compat 版本不匹配 / AuxKC 未重建 | `Tools/install-compat.sh` 重装 |
| 电池图标不显示 / 无充电状态 | 缺 `SSDT-ADPX`（无 `ACPI0003`） | 确认 EFI/OC/ACPI 与 config 的 ACPI.Add |
| 没有声音 | 缺 `keepsyms=1` 或 `alcid` 不对 | boot-args 加 `keepsyms=1 alcid=38` |
| 触摸板不工作 | VoodooI2C 未打补丁 / GPIO 引脚不对 | 用同机型仓库的 `patch_kexts.py` |
| 亮度调到最低直接黑屏 | 缺本仓库的亮度下限改动 | 见 docs/06 |
| 睡眠后黑屏、风扇不停 | 本机 S3 缺陷 | 用 `disablesleep 1` 禁止睡眠 |

## 8. 恢复到 Windows

本配置不修改内置硬盘。要回 Windows：开机按 F12 选择 Windows Boot Manager，或从 BIOS 调整启动顺序。
