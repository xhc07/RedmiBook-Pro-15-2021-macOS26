# 亮度调优：从「最低黑屏」到「最低 6.25% 无死区」

## 1. 硬件背景

| 项目 | 值 |
|---|---|
| 面板 | 天马 TL156MDMP01，eDP（DDI A） |
| 背光方式 | PWM，占空比寄存器 `0xC8258` |
| 硬件周期寄存器 | `0xC8254`（本机读回 `96000`） |
| 面板电源控制 | `PP_CONTROL = 0xC7204`（bit0=面板电源，bit2=背光使能） |
| 苹果亮度值范围 | 0 – 1024（滑块） |

## 2. 问题

WhateverXe 把苹果亮度值线性映射到占空比：

```
duty = value * hw / donor
```

苹果最低值 0 → 占空比 0 → **背光完全熄灭**，屏幕全黑。

## 3. 实测映射（修复前）

| 苹果值 | 占空比 |
|---|---|
| 0 | 0（黑屏） |
| 230 | 1.3% |
| 390 | 2.2% |
| 710 | 4.0% |
| 1350 | 7.6% |
| 2506 | 14.1% |
| 4746 | 26.7% |
| 9101 | 51.2% |
| 17741 | 99.8% |

## 4. 五轮迭代

| 版本 | 做法 | 问题 |
|---|---|---|
| v1 | 输出 clamp 到 6.25% | 滑块 0–34% 全部同亮度（死区） |
| v2 | 按比例重映射到 `[6.25%, 100%]` | 死区消失，但底部出现「反向变暗→变亮」 |
| v3 | 顶部饱和 | 无效（问题不在顶部） |
| v4 | 恒等 + 4% 下限 | 底部 4 档被合并成一档 |
| **v5** | `floor = hw/16`，`scaled = floor + value*(hw-floor)/donor` | ✅ 采用 |

## 5. 最终实现（v5）

`Patches/ours/WhateverXe-tgl-brightness-and-softsleep.patch`：

```cpp
// 处理背光占空比写入 0xC8258
if (reg == 0xC8258 && donor && hw && hw != ~0U) {
    const uint32_t floor = hw / 16;                       // 6.25%
    uint32_t scaled = floor + (uint64_t)value * (hw - floor) / donor;
    if (scaled > hw) scaled = hw;
    if (scaled < floor) scaled = floor;
    value = scaled;
}
```

## 6. 修复后的实测

| 苹果值 | 修复前 | 修复后 |
|---|---|---|
| 0 | 0%（黑屏） | 6.25% |
| 230 | 1.3% | 7.46% |
| 390 | 2.2% | 8.31% |
| 710 | 4.0% | 9.99% |
| 9101 | 51.2% | 约 53% |
| 17741 | 99.8% | 100% |

## 7. 注意事项

- 改的是 **eDP 的 `kern_xe.cpp` 路径**，不是 `kern_dsi_backlight.hpp`（那是 DSI 路径，本机不用）
- 睡眠/关屏用的不是这个占空比寄存器，而是 `PP_CONTROL (0xC7204)`，两者互不影响
- 如果亮度调到最低仍觉得太暗，可把 `floor` 从 `hw/16` 改为 `hw/12`（约 8.3%）

## 8. 如何修改

```bash
# 1. 取上游源码
git clone --branch 0.8.2 --depth 1 https://github.com/b00t0x/WhateverXe.git
# 2. 应用本仓库补丁
cd WhateverXe && git apply /path/to/Patches/ours/WhateverXe-tgl-brightness-and-softsleep.patch
# 3. 编译（需要 MacKernelSDK + Lilu 头文件，见上游文档）
python3 tools/build.py --release
# 4. 替换 EFI/OC/Kexts/WhateverXe.kext 后重启
```
