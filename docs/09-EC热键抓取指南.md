# 在 Windows 下抓取 EC 热键寄存器（只读，安全）

> 目标：找出按 **Fn+F6 / F7 / F8** 时，EC（嵌入式控制器）内存里哪个字节会变化。
> 拿到偏移和值后，就能在 macOS 侧实现对应功能。
>
> ⚠️ 全程**只读**。不要点任何 "Write"、"Set"、"Modify" 按钮。

---

## 一、准备

1. 下载 **RW-Everything**：<https://rweverything.com/download/>
   （免费，免安装，解压即用）
2. **右键 → 以管理员身份运行**（必须，否则读不了硬件）
3. 关闭其它监控软件（AIDA64、HWiNFO 等会抢 EC）

---

## 二、找到 EC 内存

本机的 EC 内存窗口地址是 **`0xFE0B0300`**（来自 ACPI 的 OperationRegion 定义）。

### 方法 A：EC 视图（优先）

1. 打开 RW-Everything
2. 看工具栏有没有 **`EC`** 或 **`Embedded Controller`** 按钮
3. 如果有，点进去，记下当前显示的值

### 方法 B：内存视图

1. 点工具栏 **`Memory`**（或 `Memory Space`）
2. 地址栏输入：`FE0B0300`
3. 长度设为 **256**（或 `100` 十六进制）
4. 会看到一片十六进制数据，**这就是 EC 内存**

### 方法 C：如果上面都是空的/失败

说明这块内存被 BIOS 隐藏或需要 EC bank 切换，请告诉我，我们换方案。

---

## 三、抓取步骤（关键）

对每个键重复以下流程：

```
1. 先记下当前整片数据（可以截图，或点 "Save" 存成 txt）
2. 按下 Fn+F6（按一次即可）
3. 立刻点 "Refresh"（刷新）再看同一片数据
4. 对比：哪个字节变了？变了之后的值是多少？
5. 等几秒让它恢复，再按一次确认可重复
```

## 四、可能遇到的情况

| 现象 | 含义 | 处理 |
|---|---|---|
| 有字节从 `0x00` 变成某个值，几秒后变回 | ✅ 找到了热键寄存器 | 记下偏移、值、恢复时间 |
| 有字节一直变化（比如计数器） | 可能是别的用途 | 记录但不作为候选 |
| 完全没有任何变化 | 按键值可能不在这个窗口 | 告诉我，我扩大范围（0xFE0B0000 起 4KB） |
| 按下后 EC 无响应（键盘失灵） | EC 忙 | 等 10 秒，别连续狂按 |

## 六、安全须知

- **只读**：RW-Everything 的写入按钮一个都别碰
- 不要改 EC 配置寄存器（可能导致风扇失控）
- 如果出现 EC 卡死（键盘失灵、无法关机）：**长按电源键 10-15 秒**强制断电，等 5 秒再开机
- 不要刷 BIOS / EC 固件

## 附：我们已经排除的路径（供参考）

| 路径 | 结论 |
|---|---|
| HID 事件 | ❌ 两轮抓取（过滤/不过滤）都没有任何事件 |
| ACPI EC 查询（`_Qxx`） | ❌ 按 F6/F7/F8 不触发任何查询 |
| ACPI WMI 通知 | ❌ 无 SCI，固件不主动通知 |
| 官方 OSD 软件 | 用户态通过 WMI 数据块**轮询**，内核驱动只写注册表 |

所以只剩"直接读 EC 内存"这一条路。
